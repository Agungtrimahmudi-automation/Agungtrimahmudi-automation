# Agung Tri Mahmudi

I build automation and AI systems, mostly to replace tedious manual work with something faster and more reliable. The projects on this profile are workflows I use myself — and a few that other people now use in their daily jobs.

An n8n pipeline that cuts a hospital's daily data recap from two hours to one minute. A duty-journal generator that saves 80% of the time spent on a monthly report. A Telegram RAG assistant that answers only from its indexed sources, and says so when the answer isn't there. A daily digest of novel rankings, a weekly smartphone ranking report, and a few experiments still in the oven. Every repository documents the problem, the flow, and the measured result, so the claims are checkable — not promises.
